# COCSheet v1.0.0

## 这是什么

COCSheet 是面向中文玩家的 CoC 7版标准规则调查员建卡工具与长期电子人物卡。它是纯前端、Local First、Zero Server 的非官方粉丝项目。

## 主要能力

- 新手引导／快速模式的 Standard CoC 7E 建卡。
- 长期人物卡，支持技能、HP／MP／SAN、Luck、背景、财富、物品与武器维护。
- 打印版人物卡，可通过浏览器打印或保存 PDF。
- 单人物导入导出、完整资料库备份与恢复。
- 建卡预设、纯前端链接分享与共享预设的本地副本。
- 调查员资料库搜索、建卡状态筛选与排序。
- 本地数据风险提示、运行异常恢复与隐私安全诊断。

## 数据保存

人物、建卡进度和建卡预设只保存在当前浏览器与当前设备，不会自动上传或同步。清理站点数据、使用无痕模式、删除浏览器资料或更换设备都可能造成数据丢失。建议定期导出完整资料库备份，并在可靠位置保存备份文件。

## 当前支持范围

当前只支持 Standard CoC 7E 的新建与规则工作流。历史文件中的其他 Setting identity 只作兼容读取、展示、备份与删除，不代表当前支持，也不会回退套用 Standard 内容。

## 浏览器

发布验证使用 Chromium 完成 production-build smoke。其他较新的现代浏览器通常可使用，但项目不对未全面验证的浏览器、打印、剪贴板或持久存储能力作完整保证。

## 升级／数据兼容

当前使用 version-1 domain 与文件格式。从先前站点版本升级到 v1.0.0 不需要 IndexedDB migration，正常浏览器中的现有数据应可直接继续读取。这不是对任意未来版本的永久兼容承诺。
